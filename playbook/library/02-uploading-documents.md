## Before you begin

Confirm you have permission to add files to the target folder. Large files may take longer depending on your storage configuration.

## Steps

1. Open **Documents** and navigate to the folder where the file belongs.
2. Click **Upload** (or drag files into the upload area when supported).
3. Select one or more files from your device.
4. Wait for the upload to complete, then verify the file name and metadata.
5. Adjust retention tags or sharing settings if your {{ entity_label }} uses them.

## Tips

- Use consistent naming (for example `YYYY-MM-DD - Council minutes.pdf`).
- Link uploaded agendas and notices from [Meetings](/playbook/meetings/overview) when the meetings package is installed.
